# Урожай подарков

**Урожай подарков** — мини-игра на Java с графическим интерфейсом. Игрок выбирает грядку, выращивает виртуальный урожай и получает случайный промокод. Одна игровая сессия длится не более **60 секунд**, а награда гарантирована.



## Как работает игра

1. **Запуск.** Игрок нажимает «Начать игру» — включается таймер.
2. **Выбор грядки.** На экране представлены три грядки; нужно выбрать одну из них.
3. **Выращивание.** Кнопка «Вырастить бонус» запускает анимацию роста.
4. **Получение приза.** Программа определяет размер скидки и партнёрскую площадку, затем показывает промокод.
5. **Использование.** На итоговом экране можно скопировать код, перейти на сайт партнёра или начать игру заново.

Если таймер заканчивается до завершения игрового действия, приз всё равно выдаётся автоматически.

## Возможности

- Оконный интерфейс на **Java Swing / Java2D**.
- Четыре экрана: старт, выбор, выращивание и результат.
- Анимация, таймер и гарантированная выдача награды.
- Три варианта скидки: **5%, 10% и 15%**.
- Случайный выбор одной из двух площадок: **«Своё Родное»** и **«Своё За Городом»**.
- Копирование промокода в буфер обмена и открытие сайта партнёра в браузере.
- Файл настроек и отдельные тесты логики выдачи призов.

### Вероятности призов

| Размер скидки | Вероятность |
|---|---:|
| 5% | 60% |
| 10% | 30% |
| 15% | 10% |

Для случайного выбора используется `SecureRandom`. Вероятности можно изменить в настройках: их сумма должна равняться 100%.

> **Примечание:** промокоды формата `DEMO-AGRO-XXXXXX` — демонстрационные, они не дают реальных скидок. Переходы ведут на сайты указанных площадок, но настоящая активация промокодов не подключена.

## Запуск программы

Требуется **Java 17 или новее**.

- **macOS:** распакуйте папку проекта и откройте `run.command`.
- **Windows:** запустите `run.bat`.
- **Linux:** выполните `./run.sh`.

Универсальная команда из папки проекта:

```bash
java -jar AgroHarvest.jar
```

Для работы самой игры интернет не нужен; он понадобится только при открытии внешнего сайта.

## Управление

- **Мышь** — нажатие кнопок и выбор грядки.
- **Enter / пробел** — старт игры или запуск выращивания после выбора.
- **1, 2, 3** — выбор грядки.
- **Esc** — возврат на старт с экрана награды.

## Настройки

Файл `config/game.properties` позволяет изменить длительность сеанса, скорость анимации, вероятности наград, названия партнёров и адреса их сайтов.

```properties
session.seconds=60
growth.millis=2700
weight.small=60
weight.medium=30
weight.large=10
```

## Структура проекта

- `AgroHarvest.jar` — готовая программа.
- `src/agro/AgroHarvest.java` — интерфейс, таймер, анимация и обработка действий.
- `src/agro/RewardEngine.java` — выбор награды, партнёра и генерация кода.
- `src/agro/GameConfig.java` — загрузка настроек.
- `src/agro/RewardEngineTest.java` — тестирование выдачи призов.
- `config/` — параметры игры.
- `screenshots/` — изображения экранов.
- `build.sh` и `test.sh` — пересборка и тесты (нужен JDK 17+).
